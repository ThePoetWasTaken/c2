# C2

> not an actual c2

## What Is This Then?

Simple userspace server that provides certain functionallities on edge computers that runs on the MIPS-I platform 

## How Can I Use This?

The script `run.sh` is designated to allow cross-compiling for the MIPS architecture and runs using qemu.

You can also `make run` directly in the root directory and it will compile for x64.
 
Frontend scripts for connecting to this are under `scripts/`. I haven't had a lot of time writing this so the code ain't great.

It was however a great learning experience for me.
